# Семья+ — прототип семейного банка

Интерактивный прототип модуля «Семья+» для ВТБ Онлайн: общий семейный бюджет, личные счета родителей, детские карты с лимитами, совместные цели, задания с наградами и элементы геймификации для развития финансовой грамотности детей.

Один HTML-файл без сборки, зависимостей и бэкенда. Открывается двойным кликом в браузере.

> ⚠️ Это учебный и демонстрационный прототип. Он не связан с ПАО ВТБ, не использует реальные банковские API и не обрабатывает настоящие деньги и персональные данные.

---

## Возможности

### Роль «Родитель»
- **Главная** — семейный бюджет с прогрессом, быстрые действия, личные счета родителей, аналитическая подсказка, расходы по категориям (кольцевая диаграмма), расходы за неделю (столбчатая диаграмма), участники семьи, ближайшая цель, задания, лента событий.
- **Семья** — перевод с личного счёта супруге или ребёнку с текстовой запиской; детские карты: баланс, лимит, пополнение на 500 ₽, заморозка; управление участниками; переключатели приватности и родительского контроля.
- **Цели** — список семейных целей, взносы фиксированной суммой (5 000 ₽) или произвольной, прогресс и остаток до цели, включение автоплатежа.
- **Задания** — создание заданий (название, описание, награда), список активных, прогресс выполнения ребёнком.
- **Ещё** — история операций с поиском и фильтрами по категориям, настройки уведомлений, блок «О сервисе».

### Роль «Ребёнок»
- **Главная** — баланс и лимит детской карты, подарок от родителя с запиской, XP и уровень, ближайшие задания, цель, бейджи.
- **Задания** — выполнение заданий с мгновенным начислением награды на карту, начислением XP и повышением уровня.
- **Цели** — семейные цели, взнос 100 ₽, подсказка «как копить быстрее».
- **Награды** — сетка бейджей (открытые и закрытые), прогресс до следующего уровня.
- **Ещё** — личная история операций и мини-уроки по финансовой грамотности.

### Общее
- Переключение ролей «Родитель / Ребёнок» — меняется навигация, палитра и контент.
- Экран поздравления при достижении цели (в том числе «Летите в Сочи!» с анимацией самолёта) и при выполнении задания.
- Bottom sheet с уведомлениями, тосты-подтверждения действий.
- Адаптивность: на десктопе — макет телефона, на экранах ≤ 420 px — на весь экран.

## Быстрый старт

1. Скачайте файл `stranichka` из репозитория.
2. Откройте его в любом современном браузере.

Сборка, npm и установка зависимостей не требуются.

## Технологии

| Слой | Решение |
|---|---|
| Разметка | HTML5, семантические секции |
| Стили | Чистый CSS, CSS-переменные, темы через `data-theme`, Grid и Flexbox |
| Логика | Vanilla JavaScript (ES6+), без фреймворков |
| Графики | Инлайновый SVG: кольцевая диаграмма через `stroke-dasharray`, столбчатая — на `div` |
| Иконки | Инлайновые SVG-спрайты, собранные функцией `ic()` |
| Шрифт | Системный стек (`-apple-system`, `Segoe UI`, `Roboto`) |
| Внешние запросы | Отсутствуют — работает офлайн |

## Структура проекта


Внутри `stranichka`:

- `<style>` — дизайн-токены (`:root`), компоненты, темы родителя и ребёнка, адаптив.
- `const state = {...}` — единственный источник данных: семья, бюджет, категории, недельная статистика, цели, задания, операции, лента, уведомления, настройки, XP и бейджи.
- Функции-экраны: `parentHome`, `parentFamily`, `parentGoals`, `parentMissions`, `parentMore`, `childHome`, `childMissions`, `childGoals`, `childAch`, `childMore`.
- `render()` — перерисовка активного экрана по `state.role` и `state.tab`.
- Делегирование событий через `data-action`, `data-tab`, `data-role`, `data-filter`, `data-toggle`.

---

## Модель данных (кратко)

```js
state = {
  role: 'parent' | 'child',
  tab: 'home' | 'family' | 'goals' | 'missions' | 'ach' | 'more',
  family: [{ id, name, role, initial, tag, balance, limit? }],
  budget, spent,
  categories: [{ id, name, amount, color }],
  weekly: [Number], weekDays: [String],
  goals: [{ id, title, icon, target, current, deadline }],
  missions: [{ id, title, desc, reward, done, tag }],
  transactions: [{ icon, title, cat, amount, who, date, note? }],
  activity, notifications, settings,
  childLevel, childXP, childXPGoal, childAchievements
}
```

Состояние живёт **только в памяти**: после перезагрузки страницы все изменения (переводы, взносы, выполненные задания) сбрасываются к исходным демо-данным.

## Ограничения прототипа

- Нет бэкенда, авторизации и базы данных — данные не сохраняются, `localStorage` не используется.
- Ввод новых заданий, целей и участников реализован через `prompt()` — упрощение для демо.
- Суммы, лимиты и статистика статичны и заданы в коде.
- Нет тестов, линтеров и CI.
- Графики рассчитаны на текущий набор категорий и не масштабируются на произвольные данные.
